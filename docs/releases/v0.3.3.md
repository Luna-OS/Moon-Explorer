Opens Downloads newest-first and adds iCloud to the sidebar.

## Download
- **Moon-Explorer-Setup-0.3.3.exe**: installer. Installs per user, no admin rights needed. It updates an older version in place.
- **Moon-Explorer-0.3.3-win-x64.zip**: portable version.

The builds are not code-signed, so Windows SmartScreen warns the first time you start them. Click "More info" and then "Run anyway".

## New
- **iCloud in the sidebar**: iCloud Drive and iCloud Photos (created by iCloud for Windows) now appear as places in the sidebar when those folders exist, so you can browse them straight from Moon Explorer. (#17)

## Changed
- **Downloads opens newest-first**: the Downloads folder now opens sorted by date modified, newest first, so a file you just downloaded is at the top, the same as Windows Explorer. Other folders keep their usual name order, and a sort you pick yourself still sticks. (#17)
