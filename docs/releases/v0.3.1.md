Improves the Open/Save dialog.

## Download
- **Moon-Explorer-Setup-0.3.1.exe**: installer. Installs per user, no admin rights needed. It updates an older version in place.
- **Moon-Explorer-0.3.1-win-x64.zip**: portable version.

The builds are not code-signed, so Windows SmartScreen warns the first time you start them. Click "More info" and then "Run anyway".

## Improved
- In the [Open/Save dialog](https://github.com/Luna-OS/Moon-Explorer/blob/main/docs/picker.md), the file list now shows only files of the chosen file type (folders always stay); "All files" shows everything. Enter confirms in open mode, like double-click. (#13)
