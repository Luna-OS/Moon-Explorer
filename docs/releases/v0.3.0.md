Adds "Run as administrator" and an Open/Save dialog mode.

## Download
- **Moon-Explorer-Setup-0.3.0.exe**: installer. Installs per user, no admin rights needed. It updates an older version in place.
- **Moon-Explorer-0.3.0-win-x64.zip**: portable version.

The builds are not code-signed, so Windows SmartScreen warns the first time you start them. Click "More info" and then "Run anyway".

## New
- **Run as administrator**: right-click a program (`.exe`, `.msi`, `.bat`, `.cmd`, `.ps1`, `.lnk` and more) and start it elevated through the Windows UAC prompt, the same as in Windows Explorer. (#11)
- **Open/Save dialog**: Moon Explorer can run as a file dialog — the whole explorer with a bar for the file name, the file type and Save / Open / Cancel — and hand the chosen path back to whatever started it. This is Moon Explorer's own dialog; it does not replace the Windows dialog that other programs show. See [docs/picker.md](https://github.com/Luna-OS/Moon-Explorer/blob/main/docs/picker.md). (#11)
