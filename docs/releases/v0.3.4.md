Keeps the tab bar from filling up.

## Download
- **Moon-Explorer-Setup-0.3.4.exe**: installer. Installs per user, no admin rights needed. It updates an older version in place.
- **Moon-Explorer-0.3.4-win-x64.zip**: portable version.

The builds are not code-signed, so Windows SmartScreen warns the first time you start them. Click "More info" and then "Run anyway".

## Fixed
- **Tabs piled up.** Opening a folder from Windows reopened all the old tabs and added one more each time. Started for a specific folder or file, Moon Explorer now shows just that; a plain start still brings your tabs back. (#19)
- **The same folder opened twice.** Opening a folder that already has a tab switches to that tab, and a saved session restores each folder once. (#19)

## New
- **Tab menu**: right-click a tab for Duplicate tab, Close tab, Close other tabs, Close tabs to the right and Reopen closed tab. (#19)
