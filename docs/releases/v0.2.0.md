Moon Explorer can now replace Windows Explorer, comes with a nicer installer and has new tools for
selections and checksums.

## Download
- **Moon-Explorer-Setup-0.2.0.exe**: installer. Installs per user, no admin rights needed.
- **Moon-Explorer-0.2.0-win-x64.zip**: portable version.

The builds are not code-signed, so Windows SmartScreen warns the first time you start them. Click "More info" and then "Run anyway".

## New
- **Use as default file manager** (Settings): folders, drives, This PC and Win+E open in Moon Explorer instead of Windows Explorer. Only for your user account, no admin rights, and you can switch back at any time. If the app was moved, it offers to register again. (#6)
- **Installer** in the Moon look: welcome and finish pages with a night-sky picture, and a **Use as default file manager** option on the last page. Uninstalling gives folders back to Windows Explorer first. (#6)
- **Select by pattern…**: select names like `*.jpg` or `IMG_2026*`; separate several patterns with `;`. (#6)
- **New folder with selection…**: moves the selected items into a new folder. One Ctrl+Z puts them back. (#6)
- **Copy name**: copies just the file names, without the path. (#6)
- **Checksums…**: SHA-256, SHA-1 and MD5 of a file, with copy buttons and a field to check a published value, e.g. to verify a download. (#6)

## If something goes wrong
If Moon Explorer was the default file manager and was deleted without uninstalling, double-clicking a folder shows an error. `scripts/reset-default-file-manager.ps1` gives folders back to Windows Explorer; see [docs/default-file-manager.md](https://github.com/Luna-OS/Moon-Explorer/blob/main/docs/default-file-manager.md).
